Overview

Wallet Creation

Generate new Ethereum wallets or import via private key & BIP39 seed phrase. AES-encrypted storage.

Live Balances

Real-time ETH balance via RPC (Infura/Alchemy). Clean portfolio dashboard with USD values.

Send & Receive

Sign and broadcast real Ethereum transactions. Receive with QR codes and clipboard copy.

Transaction History

Browse transactions with status badges (pending/confirmed/failed) and direct Etherscan links.

Secure by Design

Private keys encrypted with your password via ethers.js. In-memory only during transactions.

Admin Dashboard

Protected admin routes for wallet vault, system stats, and configuration management.

Install as unpacked extension

Follow these steps to load XWallet in Chrome developer mode

1

Clone the repository

Open a terminal, clone the repo, and install dependencies.

# Clone and install
$ git clone https://github.com/your-org/xwallet-vite-app.git
$ cd xwallet-vite-app
$ npm install
2

Build the extension

CRXJS will produce the extension bundle in app/dist/.

$ npm run build
3

Open Chrome Extensions page

Type this in your Chrome address bar and press Enter.

$ chrome://extensions
4

Enable Developer mode

Toggle the switch in the top-right corner of the Extensions page.

Developer mode ON
5

Load unpacked extension

Click Load unpacked and select the app/dist folder.

Load unpacked → select app/dist
6

Pin and launch

Click the puzzle piece icon in the Chrome toolbar, find XWallet, and pin it. Click the icon to open the popup.

XWallet is now ready Active
